# Changelog

## 1.0.0

First release: `@endosome/eslint-config-node` 1.0.0 with browser extension code linted as browser code (no
`eslint-plugin-n` rules, browser and WebExtension globals), Node.js tooling kept on the Node.js rules, and end-to-end
tests allowed to call web platform APIs in the callbacks they pass to the browser.
